# Capturas de MCP Inspector pendientes

Desde la raíz del repositorio:

```bash
npx @modelcontextprotocol/inspector python servidor_mcp.py
```

En Inspector, ejecutar `tools/list` y llamar una vez a cada herramienta:

- `buscar_documentos`: `{"consulta": "horario de visita en neonatología para abuelos"}`
- `consultar_camas`: `{"sector": "pediatría"}`
- `consultar_guardia`: `{"especialidad": "cardiología"}`
- `consultar_turnos`: `{"especialidad": "traumatología"}`
- `consultar_farmacia`: `{"medicamento": "enalapril 10 mg"}`
- `consultar_espera`: `{}`

Guardar aquí una captura legible por herramienta, mostrando nombre, argumentos y resultado. Esas capturas requieren interacción con la interfaz y forman parte de la entrega.
